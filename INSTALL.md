
# ULTRON AI Installation

## Requirements

- Windows 10 or 11
- Python 3.10 or newer
- Ollama

## Installation

1. Install Python.
2. Install Ollama.
3. Download the ULTRON-AI repository.
4. Open Command Prompt inside the project folder.
5. Install dependencies:

pip install -r requirements.txt

## Download the AI model

ollama pull llama3

## Start ULTRON

python start_ultron.py
